# ALeetCode

LeetCode 算法题解练习模块（Maven / JDK 8）。用于在掌握 Java SE 语法后巩固算法与数据结构基础。

仓库总览见根目录 [README.md](../README.md)。

---

## 环境要求

1. **JDK 8**
2. **Maven 3.6.1+**
3. IDE：IntelliJ IDEA / Eclipse

本模块无额外第三方依赖。

---

## 安装与运行

```bash
cd ALeetCode
mvn compile
```

在 IDE 中打开对应类，运行 `main` 方法即可验证题解。

---

## 题解对照

| 类 | 题目说明 |
|----|----------|
| `org.example.a_questionbank.A_One` | 两数之和 |
| `org.example.b_twentysix.A_MarSix` | 二进制字符串连续 `1` 字段判断 |

按包浏览：`a_questionbank` 为题库入门题，`b_twentysix` 为后续练习。
